# 公式オンラインショップ 商品追加手順

徳増茶道具専門店 公式サイト（https://tokumasu.co.jp）のオンラインショップに新商品を追加するときの標準手順です。
**テンプレートは既存の `product-kokuen.html`（抹茶セット6点 黒艶結晶）を使います。** 迷ったら必ずこのファイルの書き方に合わせてください。

---

## 1. 商品追加の標準フロー

ショップは **shop.html（カテゴリ一覧）→ shop-○○.html（カテゴリページ）→ product-○○.html（商品詳細）** の3階層構造です。

1. **商品情報の確認** — 商品名・価格（税・送料込み）・セット内容や寸法・StripeのURL（購入ボタン用）・一点物かどうか・**所属カテゴリ**・**商品説明文（店主が執筆したもの）**を確認する。依頼テンプレートは7章を参照
2. **画像の準備・最適化** — 元画像フォルダから画像を取り込み、幅1200pxのJPGに最適化して `images/products/商品スラッグ/` に保存（→ 3章）
3. **詳細ページの作成** — `product-kokuen.html` をコピーして `product-○○.html` を作成し、内容を書き換える（→ 2章）
4. **該当カテゴリページにカードを追加** — 商品が属するカテゴリページ（`shop-○○.html`）の商品グリッドに新商品カードを1枚追加する（→ 1-1）。**該当カテゴリが未作成の場合は、既存カテゴリページをコピーして新規作成し、shop.html のカテゴリ一覧にもカテゴリカードを追加する**（→ 1-2）
5. **sitemap.xml に追加** — 新商品ページ（カテゴリページを新規作成した場合はそれも）のURLを `sitemap.xml` の末尾（`</urlset>` の直前）に追加する。商品ページは `priority` 0.8 / `changefreq` monthly、カテゴリページは 0.8 / weekly。`lastmod` は作成日
6. **プレビュー** — ローカルでページを開き、ユーザーに見た目を確認してもらう
7. **push承認 → 公開** — ユーザーの承認を得てからPR作成・マージ・本番URL確認（→ 6章）

> ⚠️ Stripeの決済URL（`https://buy.stripe.com/...`）はユーザーがStripe管理画面で作成します。未発行の場合は先にユーザーへ依頼し、URLをもらってからページを仕上げてください。

### 1-1. カテゴリページへの商品カード追加

該当する `shop-○○.html` 内の `<!-- 商品追加はこのブロックをコピーしてください -->` 〜 `<!-- 商品追加ここまで -->` の間に、既存カードをコピーして追加します。

```html
<!-- 商品：商品名 -->
<div class="online-shop-card">
  <a href="product-○○.html" class="online-shop-card-img">
    <img src="images/products/○○/○○-01-main.jpg" alt="商品の正式名称">
  </a>
  <h3 class="online-shop-name">商品名1行目<br>商品名2行目</h3>
  <span class="online-shop-price">¥9,999</span>
  <span class="online-shop-price-note">（税・送料込み）</span>
  <a href="product-○○.html" class="online-shop-buy-btn">詳細を見る</a>
</div>
```

- カードのボタンは「詳細を見る」（購入ボタンは詳細ページ側に置く）
- 一点物の場合、価格注記は `（税・送料込み／一点限り）` にする（黒楽茶碗の例を参照）

### 1-2. カテゴリページの新規作成（該当カテゴリがない場合）

1. 既存のカテゴリページ（例：`shop-matcha-set.html`）をコピーして `shop-○○.html` を作成
2. `<head>`（title / description / canonical / OGP）とパンくず・`cat-hero` のカテゴリ名・英字ラベルを書き換え、商品グリッドを新商品のカードだけにする
3. `shop.html` の `<!-- カテゴリ追加はこのブロックをコピーしてください -->` 〜 `<!-- カテゴリ追加ここまで -->` の間に、カテゴリカードを追加する。**カードの写真はそのカテゴリの代表商品のメイン画像を流用**する

```html
<!-- カテゴリ：カテゴリ名 -->
<a href="shop-○○.html" class="category-card">
  <div class="category-card-img">
    <img src="images/products/代表商品/代表商品-01-main.jpg" alt="カテゴリ名">
  </div>
  <div class="category-card-body">
    <span class="category-card-label">ENGLISH LABEL</span>
    <span class="category-name">カテゴリ名</span><br>
    <span class="category-view">商品を見る →</span>
  </div>
</a>
```

## 2. 詳細ページ（product-○○.html）の標準構成

`product-kokuen.html` をコピーし、上から順に以下を書き換えます。ページ構成（セクションの順番）は変えないでください。

| セクション | 内容 |
|---|---|
| `<head>` | title・description・canonical・OGP・JSON-LD（下記参照） |
| ナビ＋モバイルメニュー | 変更不要（共通） |
| パンくず | `公式オンラインショップ › カテゴリ名 › 商品名` の3階層。カテゴリ名は所属カテゴリページ（`shop-○○.html`）へリンクする |
| **product-hero（`id="buy"`）** | メイン写真（`○○-01-main.jpg`）／商品タグ／商品名／価格／**「購入する」ボタン（上）**／注記2行 |
| **gallery** | ギャラリー画像（`02` 以降を順に並べる。枚数は商品による） |
| **details** | 商品説明（店主提供の説明文をそのまま掲載 → 下記「商品説明文のルール」参照。セット商品はセット内容リスト `set-list` ＋ 補足 `set-note` を併用） |
| **bottom-cta** | **「購入する」ボタン（下）**／注記2行／**特商法リンク** |
| footer＋script | 変更不要（共通） |

### 商品説明文のルール（店主提供・そのまま掲載）

商品説明文は**店主が執筆して提供します**。Claudeが楽天ページ等から説明文を起こす方式は廃止しました。

- **提供された説明文をそのまま掲載する。要約・書き換え・追記をしない**
- 誤字脱字を見つけた場合のみ、**勝手に直さず、修正前に店主へ確認を求める**
- 説明文が未提供の場合は、先に店主へ依頼する（Stripe URLと同様、揃ってからページを仕上げる）

#### HTML化のルール

説明文の**改行・段落・【見出し】構造を尊重**して整形します。

- **【 】で囲まれた行** → 小見出しスタイルにする（【 】の記号自体は外してよい）
- **その他の行** → 段落（`<p>`）として整形。原文の改行は `<br>`、空行は段落の区切りとして扱う
- 行間は読みやすく（line-height 2 前後）、色・フォントは既存デザインの世界観（黒×ゴールド×クリーム、見出しは Noto Serif JP）に合わせる

推奨マークアップ（details セクション内に配置）：

```html
<div class="product-desc">
  <p>新品。<br>伝統の友湖帛紗、本物志向の方に。<br>色：紫。</p>
  <h3 class="desc-heading">千家十職とは</h3>
  <p>表千家・裏千家・武者小路千家の三千家に仕え、茶道の道具を代々守り伝える10の名門職家を指します。…</p>
  <h3 class="desc-heading">豆知識</h3>
  <p>お点前帛紗（おてまえふくさ）は正方形ではありません。…</p>
</div>
```

```css
.product-desc{background:#fff;border:1px solid var(--border);padding:32px 28px;font-size:13px;line-height:2;color:var(--text)}
.product-desc p{margin-bottom:1.2em}
.product-desc p:last-child{margin-bottom:0}
.desc-heading{font-family:'Noto Serif JP',serif;font-weight:400;font-size:15px;letter-spacing:0.08em;color:var(--text);border-left:2px solid var(--gold);padding-left:12px;margin:2em 0 0.9em}
```

#### 説明文の実例（【見出し】構造の見本）

> 新品。
> 伝統の友湖帛紗、本物志向の方に。
> 色：紫。
> 【千家十職とは】
> 表千家・裏千家・武者小路千家の三千家に仕え、茶道の道具を代々守り伝える10の名門職家を指します。（以下略）
> 【土田友湖の概要】…
> 【歴史と特徴】…
> 【出品情報】…
> 【豆知識】
> お点前帛紗（おてまえふくさ）は正方形ではありません。

→ 冒頭3行は1つの段落（`<br>`区切り）、【千家十職とは】以降は「小見出し＋段落」の繰り返しとしてHTML化する。

### 帛紗（ふくさ）カテゴリの注意書きセクション（必須）

**カテゴリが帛紗（ふくさ）の場合は、素材に応じて注意書きテンプレートを選んで商品説明の後に挿入する（正絹→A、人絹・化繊→B）。** 素材が不明な場合は店主に確認する。

| テンプレート | 対象素材 | スニペット（挿入用HTML） | 原文マスター |
|---|---|---|---|
| A | 正絹 | `docs/snippets/fukusa-notice-A-shoken.html` | `docs/snippets/fukusa-notice-A-shoken.txt` |
| B | 人絹・化繊 | `docs/snippets/fukusa-notice-B-kasen.html` | `docs/snippets/fukusa-notice-B-kasen.txt` |

#### 挿入方法

スニペットファイルの中身（`<!-- 帛紗注意書き（…）ここから -->` 〜 `ここまで -->` の全体）をそのまま、**商品説明セクションの閉じタグ `</section>` と `<section class="bottom-cta">` の間**に貼り付ける。スニペットはインラインスタイルのみで完結しているため、ページ側のCSSに追加は不要。挿入後に以下で原文一致を検証する。

```bash
python3 docs/snippets/fukusa_notice_tool.py check
```

- 注意書きの本文は原文マスター（.txt）と一字一句同じものを掲載する。**要約・書き換え・追記をしない**
- マーカー（ここから／ここまで）のコメントは削除しない（検証・貼り替えの目印になる）

#### 注意書きの文言を将来変更する場合の手順

静的サイトのため、スニペットを直しただけでは掲載済みページには反映されない。以下の順で行う。

1. 原文マスター `docs/snippets/fukusa-notice-A-shoken.txt`（または `-B-kasen.txt`）を編集する
2. `python3 docs/snippets/fukusa_notice_tool.py build` を実行してスニペットHTMLを再生成する
3. 掲載済みの各商品ページについて、マーカー（ここから〜ここまで）の間を新しいスニペットの中身で貼り替える（掲載済みページは手順4のcheckが自動で列挙してくれる）
4. `python3 docs/snippets/fukusa_notice_tool.py check` を実行し、全スニペット・全掲載ページが原文と完全一致（✅）することを確認する

### `<head>` の書き換えチェックリスト

- [ ] `<title>` — `商品名｜公式オンラインショップ｜徳増茶道具専門店`
- [ ] `meta description` — 商品の紹介文＋「公式オンラインショップでクレジットカード決済にてご購入いただけます」
- [ ] `canonical` / `og:url` — `https://tokumasu.co.jp/product-○○.html`
- [ ] `og:title` / `og:image` / `twitter:title` / `twitter:image` — 商品名とメイン画像のフルURL
- [ ] JSON-LD（Product構造化データ）— name / image / description / price を書き換え。`availability` は在庫ありなら `InStock`
- [ ] Googleタグ（gtag）はそのまま残す

## 3. 画像の仕様

| 項目 | 仕様 |
|---|---|
| 幅 | **1200px**（メイン画像は 1200×1200 の正方形推奨。カードとヒーローが正方形表示のため） |
| 形式 | **JPG**（品質80前後で圧縮。目安：1枚 300KB 以下） |
| 保存先 | `images/products/商品スラッグ/`（例：`images/products/kokuen/`） |
| 命名 | `スラッグ-連番-内容.jpg`（例：`kokuen-01-main.jpg`, `kokuen-02-bowl.jpg`, `kokuen-11-box.jpg`）。`01-main` は必ずメイン写真 |

### 元画像の場所

```
~/SynologyDrive1/SynologyDrive/02_商品_カタログ/リベシティ市場画像ほか/リベ出品商品/徳増ホームページ出品商品画像/
```

この中の**商品別フォルダ**（例：`黒艶結晶5点詳細`、`黒楽一期一会詳細`、`碧釉衛生的詳細`、`茶篩い詳細`）から元画像を取得します。新商品のフォルダが見当たらない場合はユーザーに確認してください。

### 最適化コマンド（Mac標準の sips を使用）

```bash
# 幅1200pxにリサイズしてJPG（品質80）で書き出す例
sips -Z 1200 -s format jpeg -s formatOptions 80 "元画像.png" --out "images/products/○○/○○-01-main.jpg"
```

- 元画像（Synology側）は**削除・上書きしない**。リポジトリには最適化後のJPGだけを入れる
- PNGやHEICで支給された場合も必ずJPGに変換する

## 4. 一点物商品の特別対応

一点物（在庫1点のみ）の商品は、`product-kuroraku-ichigoichie.html`（黒楽茶碗 銘「一期一会」）を参考に、通常の手順に加えて以下を行います。

### 販売中の表記

- 商品タグを `ONE OF A KIND · 一点物` にする
- 価格注記の下に **`※一点限りの商品です。`** を表示する（`one-of-a-kind-note`）
- セット内容リストに「一点限りの商品です。同じものは二つとございません」の行を入れる
- カテゴリページのカード価格注記は `（税・送料込み／一点限り）` にする

### 売り切れ時の SOLD OUT 切り替え手順

売れたら**速やかに**（できれば当日中に）以下を切り替えて公開します。

1. **詳細ページ（上下2か所とも）**：「購入する」ボタンを SOLD OUT 表示に差し替える
   ```html
   <!-- 変更前 -->
   <a href="https://buy.stripe.com/..." target="_blank" rel="noopener" class="buy-btn">購入する</a>
   <!-- 変更後（リンクなしの表示に変える。secure-note / order-note の2行は削除してよい） -->
   <span class="buy-btn" style="background:#555;color:rgba(255,255,255,0.7);cursor:default">SOLD OUT</span>
   ```
2. **JSON-LD**：`"availability": "https://schema.org/InStock"` → `"https://schema.org/SoldOut"` に変更
3. **カテゴリページのカード**：「詳細を見る」ボタンはそのまま残し、価格注記を `（税・送料込み／完売しました）` に変更。売り切れが伝わるよう、商品名の下などに `SOLD OUT` の表記を追加する。カテゴリ一覧（shop.html）のカード写真にその商品を使っている場合は、別の販売中商品の写真に差し替える
4. **Stripe側**：ユーザーに決済リンクの無効化を依頼する（ページを直しても旧URLから買えてしまうのを防ぐため）

## 5. デザイン原則

既存ページの世界観を必ず踏襲します。新しい色・フォント・装飾を勝手に足さないでください。

- **配色**：黒 × ゴールド × クリーム。CSS変数をそのまま使う
  - `--black:#0d0d0d` ／ `--gold:#c8a96e` ／ `--gold-light:#e8d5a3` ／ `--cream:#f5f0e8` ／ `--text:#1a1a1a` ／ `--muted:#6b6b6b` ／ `--border:#d4c9b0`
- **フォント**：本文は Noto Sans JP、見出し・商品名は Noto Serif JP、英字ロゴ・数字は Cormorant Garamond
- **トーン**：余白広め、文字間広め（letter-spacing）、装飾は控えめ。角丸・影・派手なアニメーションは使わない
- **文体**：ですます調。上から目線・誇大表現はNG
- CSSは各HTMLに埋め込み式（外部CSSなし）。テンプレートのスタイルをそのまま持っていけばよい

## 6. 公開フロー（プレビュー → push承認 → 本番確認）

**ユーザーの承認なしに push・PR作成をしないこと。**

1. **ローカルプレビュー** — 作成した `product-○○.html` と `shop.html` をブラウザで開き、スマホ幅（375px）とPC幅の両方でユーザーに見せる
2. **修正対応** — ユーザーの指摘を反映し、再度プレビュー
3. **承認確認** — ユーザーが「OK」「pushして」と明言してから次へ進む
4. **PR作成** — 作業ブランチ（`claude/○○` 形式）からコミットし、`main` に向けてPRを作成。マージはユーザーの指示に従う
5. **本番確認** — マージ後、以下を実際に開いて確認する
   - `https://tokumasu.co.jp/shop-○○.html`（カテゴリページ）に新商品カードが表示されること
   - `https://tokumasu.co.jp/product-○○.html` が表示され、画像が全部読み込まれること
   - パンくず・「一覧へ戻る」リンクがカテゴリページに正しく飛ぶこと
   - 「購入する」ボタンからStripeの決済画面が開くこと（決済は完了させない）
   - カテゴリを新規作成した場合は `https://tokumasu.co.jp/shop.html` にカテゴリカードが表示されること

## 7. 商品追加の依頼テンプレート

店主はこのテンプレートをコピーして Claude Code に渡すだけで商品追加を依頼できます。

